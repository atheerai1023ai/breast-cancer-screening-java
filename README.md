# breast-cancer-screening-java

## Overview

This project is a Java desktop application developed using Java Swing to simulate a breast cancer screening management system. The application provides a graphical user interface that guides users through the screening process, from login and hospital selection to patient examination and confirmation.

The project was developed to demonstrate object-oriented programming principles, event-driven programming, and desktop GUI development using Java.

---

## Features

- Secure user login interface
- Interactive graphical user interface (GUI)
- Hospital selection
- Initial patient examination workflow
- Confirmation and navigation screens
- Multi-window desktop application
- Image-based interface components

---

- Java Swing
- Object-Oriented Programming (OOP)
